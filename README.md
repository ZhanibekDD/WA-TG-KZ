# Qazyna — привычный мессенджер для Казахстана

Интерактивный интерфейс мессенджера: чаты на первом экране, знакомая переписка, группы, статусы, каналы, сообщества и звонки. Рабочее название — Qazyna; самостоятельный продукт, не официальный клиент WhatsApp или Telegram.

**Статус: демонстрационный прототип интерфейса, не работающая сеть.** Все контакты и исходные сообщения вымышлены. Добавленные сообщения, вложения, группы, статусы и настройки существуют только в текущей вкладке и исчезают после её перезагрузки. Не добавляйте конфиденциальные данные.

## Текущее направление

Визуальный и навигационный ориентир — актуальный WhatsApp Android/Web: плотность списка чатов, верхние панели, фильтры, мобильная нижняя навигация, геометрия переписки, композер, меню и выбор контакта. Название, логотип и собственные ассеты остаются Qazyna.

Пока visual parity не принят, в основной интерфейс не добавляются экспериментальные темы и собственная навигация, которые уводят продукт от выбранного эталона.

| Сценарий | Реализация в этой версии |
|---|---|
| Главный экран | Список чатов, постоянный поиск, фильтры «Все / Непрочитанные / Избранное / Группы», архив |
| Избранное | Favorites — отдельный список любимых чатов; не смешивается с закреплениями или starred messages |
| Избранные сообщения | Сообщение помечается в исходной переписке; отдельный список ведёт обратно в исходный чат |
| Чат с собой | Отдельный Message Yourself «Вы / Сіз»; starred messages туда не копируются |
| Новый чат | На телефоне полноэкранный Select contact: новая группа, новый контакт, новое сообщество, затем контакты |
| Телефон | Отдельные экраны списка и переписки; внизу «Чаты / Обновления / Сообщества / Звонки»; настройки открываются из More |
| Компьютер | WhatsApp-Web-подобная полноэкранная компоновка: rail, список слева, чат справа; Chats header содержит реальное действие «Новый чат» и More |
| Переписка | Текст, эмодзи, цитата, starred, редактирование и удаление своих сообщений, черновик для каждого чата |
| Действия над сообщением | Context menu возле сообщения: reply, copy, star/unstar, edit/delete для своих сообщений |
| Композер | Emoji, вложение, фото/камера и отдельная кнопка микрофона/отправки в WhatsApp-подобной геометрии |
| Вложения | Локальный просмотр изображения, воспроизведение готового аудиофайла, скачивание файла |
| Организация | Архив, закрепления, mute, Favorites |
| Группы | Создание группы из вымышленных контактов без отправки приглашений |
| Обновления | Горизонтальный tray статусов; каналы находятся здесь и не смешиваются с обычным списком Chats |
| Сообщества | Отдельная основная вкладка с честным onboarding/empty state без вымышленных сообществ |
| Настройки | RU / қазақша; визуальная палитра зафиксирована на parity-эталоне |
| Звонки и запись голоса | WhatsApp-подобная зона/empty state без выдуманной истории; камера и микрофон не запрашиваются автоматически |

Вложения не отправляются на сервер. Лимиты: 10 МиБ на файл, 30 МиБ одновременно удерживаемых вложений в сессии. Активные форматы вроде HTML/SVG не встраиваются в страницу.

## Чего пока нет

- регистрации по номеру телефона и настоящих аккаунтов;
- доставки между устройствами, серверного хранения и синхронизации;
- уведомлений, офлайн-очереди и реальных статусов доставки/прочтения;
- системной адресной книги и настоящего создания контактов;
- записи с микрофона, аудио- и видеозвонков;
- сквозного шифрования, аудита безопасности и подтверждённого размещения данных в Казахстане.

Значок часов у нового сообщения означает только добавление в эту вкладку. Это не подтверждение доставки. Mute меняет демонстрационную настройку: реальные уведомления не подключены.

Наличие web manifest не означает проверенную установку на всех телефонах или поддержку офлайн-режима.

## Visual parity acceptance

Контрольные размеры и правила приёмки зафиксированы в [docs/WHATSAPP_PARITY_ACCEPTANCE.md](docs/WHATSAPP_PARITY_ACCEPTANCE.md). Ключевые мобильные размеры: 360×800, 390×844 и 412×915; desktop: 1366×768, 1440×900 и 1920×1080. После утверждения базовых скриншотов дальнейшие изменения должны проверяться на визуальный дрейф.

## Разработка и проверки

Требуется Node.js 22.13+.

~~~bash
npm ci
npm run dev
~~~

~~~bash
npm test
npm run lint
~~~

Pull request CI автоматически выполняет production build, TypeScript, ESLint и полный набор тестов. Тесты проверяют переходы состояния, изоляцию переписок, Favorites/Starred/Message Yourself, каналы, фильтры, действия с сообщениями, parity-контракты и HTML производственной сборки. Они не заменяют пиксельную проверку на реальных viewport.

## Следующий рабочий результат

После визуальной приёмки — первый настоящий вертикальный срез: два аккаунта на разных устройствах обмениваются сообщениями; сообщения сохраняются, повторная отправка не создаёт дублей, восстановление соединения не теряет переписку.

Подробности: [docs/PRODUCT_ROADMAP.md](docs/PRODUCT_ROADMAP.md).

## Технологии

React 19, TypeScript, Vinext, Tailwind CSS, Radix UI и Lucide. Текущая сборка совместима с Cloudflare Workers; это техническая характеристика прототипа, а не заявление о независимой инфраструктуре.

Секреты и ключи провайдеров не должны попадать в этот публичный репозиторий. Решения о сервере, поставщиках, размещении данных и публикации принимаются отдельно.
