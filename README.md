# Qazyna — привычный мессенджер для Казахстана

Интерактивный интерфейс мессенджера: чаты на первом экране, знакомая переписка, группы, каналы и избранное. Рабочее название — Qazyna; самостоятельный продукт, не официальный клиент WhatsApp или Telegram.

**Статус: демонстрационный прототип интерфейса, не работающая сеть.** Все контакты и исходные сообщения вымышлены. Добавленные сообщения, вложения, группы, статусы и настройки существуют только в текущей вкладке и исчезают после её перезагрузки. Не добавляйте конфиденциальные данные.

## Что изменилось

Предыдущая концепция ленты, сообществ и каталога услуг заменена по запросу владельца проекта. Главный принцип: человеку не нужно заново учиться общаться.

| Сценарий | Реализация в этой версии |
|---|---|
| Главный экран | Список чатов, поиск по именам и текстам, фильтры «Все / Непрочитанные / Группы / Каналы» |
| Телефон | Список и переписка — отдельные экраны; внизу «Чаты / Обновления / Звонки / Настройки» |
| Компьютер | Список слева, переписка справа, компактная навигация |
| Переписка | Текст, эмодзи, цитата, редактирование и удаление своих сообщений, черновик для каждого чата |
| Вложения | Локальный просмотр изображения, воспроизведение готового аудиофайла, скачивание файла |
| Организация | Архив, закрепления, отметка «без звука», избранное |
| Группы | Создание группы из вымышленных контактов без отправки приглашений |
| Обновления | Локальные текстовые статусы и демонстрационные каналы, подписка/отписка |
| Настройки | Полный набор подписей RU / қазақша, зелёная или голубая тема |
| Звонки и запись голоса | Понятное сообщение о недоступности; камера и микрофон не запрашиваются |

Вложения не отправляются на сервер. Лимиты: 10 МиБ на файл, 30 МиБ одновременно удерживаемых вложений в сессии. Активные форматы вроде HTML/SVG не встраиваются в страницу.

## Чего пока нет

- регистрации по номеру телефона и настоящих аккаунтов;
- доставки между устройствами, серверного хранения и синхронизации;
- уведомлений, офлайн-очереди и реальных статусов доставки/прочтения;
- записи с микрофона, аудио- и видеозвонков;
- сквозного шифрования, аудита безопасности и подтверждённого размещения данных в Казахстане.

Значок часов у нового сообщения означает только добавление в эту вкладку. Это не подтверждение доставки. «Без звука» меняет демонстрационную настройку: реальные уведомления не подключены.

Наличие web manifest не означает проверенную установку на всех телефонах или поддержку офлайн-режима.

## Разработка и проверки

Требуется Node.js 22.13+.

~~~bash
npm ci
npm run dev
~~~

~~~bash
npm test
npm run lint
~~~

Тесты проверяют переходы состояния мессенджера, изоляцию переписок, фильтры, действия с сообщениями, полноту переводов и HTML производственной сборки. Они не заменяют проверку интерфейса на настоящих телефонах.

## Следующий результат

Первый рабочий вертикальный срез: два настоящих аккаунта на разных устройствах обмениваются сообщениями; сообщения сохраняются, повторная отправка не создаёт дублей, восстановление соединения не теряет переписку.

Подробности: [docs/PRODUCT_ROADMAP.md](docs/PRODUCT_ROADMAP.md).

## Технологии

React 19, TypeScript, Vinext, Tailwind CSS, Radix UI и Lucide. Текущая сборка совместима с Cloudflare Workers; это техническая характеристика прототипа, а не заявление о независимой инфраструктуре.

Секреты и ключи провайдеров не должны попадать в этот публичный репозиторий. Решения о сервере, поставщиках, размещении данных и публикации принимаются отдельно.
