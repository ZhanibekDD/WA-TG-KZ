# Qazyna

Рабочий MVP казахстанской социальной платформы: личные чаты, локальная лента, сообщества и проверенные городские сервисы в одном продукте.

> **Статус:** product prototype / Phase 1. Интерфейс и ключевые сценарии работают, данные пока демонстрационные и хранятся только в текущей сессии браузера. Это не production-мессенджер и не заявленная реализация сквозного шифрования.

## Почему продукт не копирует WhatsApp

Обычный мессенджер без существующего круга контактов не имеет причины для перехода. Qazyna начинает с локальной пользы, которую пользователь получает ещё до приглашения друзей:

- городская и профессиональная лента;
- сообщества Казахстана;
- проверенные специалисты и компании;
- полноценные личные и групповые чаты;
- интерфейс на казахском и русском языках;
- PWA: приложение можно установить с браузера.

## Что уже работает

- адаптивный интерфейс для телефона и компьютера;
- переключение между лентой, чатами, сообществами и сервисами;
- публикация нового поста и реакции;
- выбор чата, поиск по чатам и отправка сообщений;
- вступление в сообщества;
- переключение ҚАЗ / RU;
- installable PWA manifest;
- Cloudflare/Vinext production build.

## Запуск

Требуется Node.js 22.13+.

```bash
npm ci
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm test
```

## Следующая продуктовая версия

1. Регистрация по номеру телефона с защитой от SIM-swap.
2. Реальные профили, контакты, посты, комментарии и группы.
3. Realtime-доставка сообщений, push-уведомления и офлайн-очередь.
4. Фото, видео, документы и голосовые сообщения.
5. E2EE для личных чатов на основе проверенного протокола, а не собственной криптографии.
6. Модерация, жалобы, антиспам и прозрачная апелляция.
7. Серверы и резервные копии в Казахстане, аудит ИБ и соответствие законодательству РК.

## Технологии

- React 19 + TypeScript
- Next.js-compatible Vinext runtime
- Tailwind CSS
- Cloudflare Workers-compatible ESM
- Shadcn primitives + Lucide icons

## Важное перед публичным запуском

Qazyna — рабочее название. До рекламы и регистрации домена нужно провести проверку товарных знаков и юридических наименований. Репозиторий публичный, поэтому секреты, ключи SMS-провайдера и production-конфигурация не должны попадать в Git.
