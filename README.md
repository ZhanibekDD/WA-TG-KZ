# Qazyna — привычный мессенджер для Казахстана

Интерактивный интерфейс мессенджера с WhatsApp-parity направлением. Рабочее название — Qazyna; самостоятельный продукт, не официальный клиент WhatsApp или Telegram.

**Статус: демонстрационный прототип интерфейса, не работающая сеть.** Все контакты и исходные сообщения вымышлены. Добавленные сообщения, вложения, группы, статусы и настройки существуют только в текущей вкладке и исчезают после её перезагрузки. Не добавляйте конфиденциальные данные.

## Текущее направление

Визуальный и навигационный ориентир — стабильный WhatsApp Android/Web. Название, логотип и собственные ассеты остаются Qazyna. Основная цель текущей ветки — максимально близкая геометрия и привычное поведение без возврата к самостоятельному generic-messenger дизайну.

| Сценарий | Реализация в этой версии |
|---|---|
| Главный экран | Список чатов, поиск, архив, фильтры «Все / Непрочитанные / Избранное / Группы» |
| Favorites | Отдельный список любимых чатов, не связанный с pinning |
| Starred messages | Звёздочка хранится на исходном сообщении; отдельный список ведёт обратно в исходный чат |
| Message Yourself | Отдельный чат «Вы / Сіз»; starred messages туда не копируются |
| Телефон | «Чаты / Обновления / Сообщества / Звонки»; Settings через More |
| Новый чат | Полноэкранный Select contact: новая группа / новый контакт / новое сообщество / контакты |
| Компьютер | WhatsApp-Web-подобная rail + список чатов + переписка |
| Переписка | Текст, emoji, reply, edit/delete своих сообщений, star, contextual menu |
| Композер | Emoji, вложение, камера и отдельная mic/send кнопка |
| Вложения | Локальный просмотр изображения, готового аудиофайла и скачивание файла |
| Обновления | Status tray и отдельные Channels; каналы не смешиваются с Chats |
| Сообщества | Отдельная основная вкладка без вымышленных membership-данных |
| Настройки | RU / қазақша; визуальная палитра зафиксирована на parity-эталоне |
| Звонки | Честное пустое состояние; реальных звонков пока нет |

## Strict visual baseline

Последним импортируется `app/whatsapp-strict-2026.css`. Он фиксирует ключевую геометрию мобильного и desktop UI. Подробности и текущий capture-gate: [docs/WHATSAPP_STABLE_BASELINE_2026-09-02.md](docs/WHATSAPP_STABLE_BASELINE_2026-09-02.md).

GitHub Actions выполняет не только production build / TypeScript / ESLint / tests, но и реальный Chromium visual-capture. После успешной проверки к run прикладывается artifact `whatsapp-parity-screenshots` с PNG для Chats, Chat, New chat, Updates, Calls и Desktop на контрольных viewport.

Кодовые и CSS-проверки сами по себе не дают права называть результат pixel-perfect. Для этого нужен screenshot-diff относительно утверждённых WhatsApp reference screens.

## Чего пока нет

- регистрации по номеру телефона и настоящих аккаунтов;
- доставки между устройствами, серверного хранения и синхронизации;
- уведомлений и reconnect/offline очереди;
- адресной книги устройства;
- записи с микрофона, аудио- и видеозвонков;
- сквозного шифрования и независимого security-аудита.

## Следующий рабочий результат

После visual acceptance — первый настоящий вертикальный срез: регистрация по номеру, два аккаунта на разных устройствах, server persistence, realtime delivery, reconnect без дублей и честные статусы доставки.

Технологии: React 19, TypeScript, Vinext, Tailwind CSS, Radix UI и Lucide. Текущая сборка совместима с Cloudflare Workers; решения о production-инфраструктуре и хранении данных принимаются отдельно.
